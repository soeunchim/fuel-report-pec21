# ប្រព័ន្ធគ្រប់គ្រងរបាយការណ៍ប្រេង គ.ជ.ប | គណៈកម្មការរៀបចំការបោះឆ្នោតខេត្តតាកែវ (PEC21)

កម្មវិធីគ្រប់គ្រងរបាយការណ៍ប្រេងទំនើប ស្តង់ដារជាតិ រៀបចំឡើងតាមលំនាំរចនាបថផ្លូវការរបស់ គ.ខ.ប ២១ ខេត្តតាកែវ គាំទ្រការដំណើរការបានគ្រប់កាលៈទេសៈ ទាំង Offline និង Online។

---

## 🌟 លក្ខណៈពិសេសចម្បង (Key Features)

### ១. របៀបដំណើរការ និងទីតាំងផ្ទុកទិន្នន័យ ៤ របៀប + Dual Storage (Storage Modes)
- **របៀបទី ១ (Local Database):** ដំណើរការលើកុំព្យូទ័រតែមួយ `http://localhost:3027` ដោយមិនចាំបាច់មានអ៊ីនធឺណិត (Offline)។
- **របៀបទី ២ (Local Wi-Fi ផ្ទៃក្នុង):** កុំព្យូទ័រធ្វើជាម៉ាស៊ីនបម្រើ បើកឱ្យទូរស័ព្ទដៃ ឬកុំព្យូទ័រផ្សេងទៀតក្នុងបន្ទប់ធ្វើការតភ្ជាប់តាម Wi-Fi/Hotspot ជាមួយ QR Code ស្កេនចូលភ្លាមៗ។
- **របៀបទី ៣ (Online Database):** ត្រៀមរួចជាស្រេចសម្រាប់ដាក់ឱ្យដំណើរការលើ Cloud (Render, Railway, VPS) ប្រើប្រាស់បានពីគ្រប់ទីកន្លែង។
- **របៀបទី ៤ (Google Sheet):** ធ្វើសមកាលកម្មទិន្នន័យទៅកាន់ Google Sheet ដោយផ្ទាល់តាមរយៈ Google Apps Script Web App។
- **ដំណើរការទាំងពីរព្រមគ្នា (Dual Storage):** រក្សាទុកក្នុង Database ផង និង Sync ទៅកាន់ Google Sheet ដោយស្វ័យប្រវត្តិ (Real-time Dual Sync)។

### ២. គណនី និងសិទ្ធិប្រើប្រាស់ (User Roles)
ប្រព័ន្ធបានកំណត់សិទ្ធិ និងបង្កើតគណនីលំនាំដើមចំនួន ៥ ប្រភេទស្របតាមការស្នើសុំ៖

| ល.រ | ឈ្មោះគណនី (Username) | ពាក្យសម្ងាត់ (Password) | តួនាទី (Role) | ការពិពណ៌នា |
| :---: | :--- | :--- | :--- | :--- |
| **១** | `superadmin` | `admin123` | **SuperAdmin** | អភិបាលជាន់ខ្ពស់ មានសិទ្ធិពេញលេញគ្រប់គ្រងប្រព័ន្ធទាំងអស់ |
| **២** | `admin` | `admin123` | **Admin** | អភិបាលទូទៅ គ្រប់គ្រងទិន្នន័យ របាយការណ៍ និងគណនី |
| **៣** | `pec21` | `pec123` | **PEC21** | គណៈកម្មការរៀបចំការបោះឆ្នោត ត្រួតពិនិត្យ និងអនុម័ត |
| **៤** | `officer` | `officer123` | **មន្ត្រី ល.ខ.ប** | មន្ត្រីលេខាធិការដ្ឋាន ពិនិត្យទិន្នន័យ និងបោះពុម្ពឯកសារ |
| **៥** | `clerk` | `clerk123` | **អ្នកបញ្ចូលទិន្នន័យ** | បញ្ចូលទិន្នន័យបញ្ចេញប្រេង និងធ្វើសំណើសុំប្រេង |

### ៣. ការបោះពុម្ព និងនាំចេញឯកសារជា Word និង Excel (Print & Export)
ប្រព័ន្ធភ្ជាប់មកជាមួយគំរូឯកសារផ្លូវការ ១០០% ស្របតាមទម្រង់រដ្ឋបាលជាតិ៖

1. **របាយការណ៍ប្រេងឥន្ធនៈ (Excel .xlsx):** 
   - នាំចេញជា File Excel ដែលមានរូបមន្តគណនាសមតុល្យដើមគ្រា បញ្ចូល បញ្ចេញ និងសល់ចុងគ្រា ព្រមទាំងសន្លឹក `បញ្ជីរាយនាម`, `ការប្រើប្រាស់ប្រេងឥន្ធនៈ`, `របាយការណ៍ប្រចាំខែ`, និង `Link` សម្រាប់ Mail Merge។
2. **ប័ណ្ណបញ្ចេញប្រេង (Word .docx):** 
   - នាំចេញជា File Word ប័ណ្ណបញ្ចេញប្រេងផ្លូវការ និងអាចមើលគំរូបោះពុម្ព (Live Print Preview) ក្នុងកម្មវិធី។
3. **សំណើ (Word .docx):** 
   - នាំចេញជា File Word លិខិតសំណើសុំប្រេងជូនលោកស្រីប្រធាន ល.ខ.ប ដោយមានការបំលែងចំនួនជាអក្សរខ្មែរស្វ័យប្រវត្តិ។
4. **របាយការណ៍ហិរញ្ញវត្ថុ (Word .docx):** 
   - នាំចេញជា File Word របាយការណ៍បេសកកម្មការងារ និងពិនិត្យការិយាល័យបោះឆ្នោតតាមឃុំ/ស្រុក យោងតាមលិខិតឧទ្ទេសនាម។
5. **របាយការណ៍ប្រើប្រាស់ប្រេង (Word .docx):** 
   - នាំចេញជា File Word របាយការណ៍បូកសរុបការប្រើប្រាស់ប្រេងឥន្ធនៈប្រចាំខែ គោរពជូនឯកឧត្តមប្រធាន គ.ជ.ប។

## 🚀 របៀបចាប់ផ្តើមដំណើរការលើ Windows (How to Run)

### វិធីទី ១៖ ចុចពីរដងលើឯកសារ `start.bat` (ងាយស្រួលបំផុត)
- គ្រាន់តែចុចពីរដង (Double click) លើឯកសារ **`start.bat`** នោះប្រព័ន្ធនឹងដំណើរការ Server និងបើក Browser ចូលកម្មវិធីដោយស្វ័យប្រវត្តិ!

### វិធីទី ២៖ ដំណើរការតាម Command Line
```powershell
npm start
```
បន្ទាប់មកបើក Browser វាយអាសយដ្ឋាន៖ `http://localhost:3027`

## ☁️ ការភ្ជាប់ Google Sheet (Google Apps Script)
១. បង្កើត Google Sheet ថ្មីមួយនៅលើ Google Drive របស់អ្នក។
២. ចូលទៅកាន់ម៉ឺនុយ **Extensions** -> **Apps Script**។
៣. ចម្លងកូដនៅក្នុងឯកសារ `google-apps-script.js` ទៅបិទភ្ជាប់ក្នុងនោះ។
៤. ចុច **Deploy** -> **New deployment** -> ជ្រើសរើស **Web app** -> Who has access: **Anyone** -> ចុច **Deploy**។
៥. ចម្លង Web App URL យកមកបិទភ្ជាប់ក្នុងផ្ទាំង **"ការកំណត់ & Cloud (Settings)"** នៅក្នុងកម្មវិធី រួចចុច **"ធ្វើសមកាលកម្មភ្លាមៗ"**។
